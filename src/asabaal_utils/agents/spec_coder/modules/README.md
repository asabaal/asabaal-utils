# Core Modules

## Module Implementation Files

This directory contains the actual Python module implementations that are documented in the module-specific notebooks.

## 📁 Module Structure

Each module corresponds to a notebook in `../notebooks/module_specific/`:

### Foundation Modules
- `file_utils.py` - File operations utilities
- `parsers.py` - YAML/JSON parsing tools  
- `path_manager.py` - Path handling utilities

### Analysis Modules
- `ast_analyzer.py` - Code analysis tools
- `spec_handler.py` - Specification handling
- `quality_checker.py` - Quality assurance

### Generation Modules
- `code_generator.py` - Code generation tools
- `test_framework.py` - Testing framework
- `doc_generator.py` - Documentation generation

## 🔧 Module Design Principles

Each module follows these principles:

1. **Single Responsibility** - Each module has one clear purpose
2. **Full Documentation** - Every function and class is documented
3. **Error Handling** - Comprehensive error handling and validation
4. **Type Hints** - Full type annotations for better IDE support
5. **Test Coverage** - Each module has corresponding tests
