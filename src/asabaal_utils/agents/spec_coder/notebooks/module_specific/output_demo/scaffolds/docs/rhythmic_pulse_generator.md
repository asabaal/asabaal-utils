# Rhythmic Pulse Generator

## Project Overview

The Rhythmic Pulse Generator is a Python library designed to create rhythmic pulse patterns with specified BPM and duration. It provides functionality to generate pulses, apply ADSR envelopes, and export the resulting audio as a file. The library is ideal for music production, sound design, and rhythm generation applications.

## Installation Instructions

```bash
pip install rhythmic-pulse-generator
```

## Usage Examples

### Generate Pulse Example

```python
from rhythmic_pulse_generator import generate_pulse

# Generate a 120 BPM pulse pattern for 4 seconds
pulse_pattern = generate_pulse(bpm=120, duration=4.0)
print(pulse_pattern)
```
